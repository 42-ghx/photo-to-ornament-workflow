图片生成 · Codex

使用当前对话的 Codex 图像工具。网页提交任务后显示「等待 Codex 图像工具」；在对话中发送任务编号，Codex 执行后结果会自动回到节点。网页无法自行调用对话工具，也不会显示虚假的生成百分比。

四步图像流程

  1. 补全与透明抠图：保留可见结构，补足局部缺失；推断部分属于艺术重建。
  2. 柔光参考：减弱强反光和大面积阴影，保留局部读形。
  3. 主纹剪影：白色表示装饰实体；刻线和眼部凹陷保留实体支撑。
  4. 连续高度：保留刻线、眼部凹陷与细微起伏，并与剪影保持相同布局。

UV 遮罩匹配 · 提供模型后

提供模型后，可添加「模型 UV 读取」，读取 OBJ 已有 UV，或导入与模型对应的 UV 遮罩，再按白色范围匹配图像。没有模型时只进行前四步。模型需要自带 UV。

版本与导出

每次生成保存独立版本。用节点中的版本选择或前后箭头回退；单图下载、节点打包与全项目打包均可使用。导出项目 JSON 可保存节点参数和连接。
