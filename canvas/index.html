在节点内编辑提示词和参数，选择上游输入后点击「重新生成」。拖动节点标题调整布局；滚轮缩放，拖动空白平移。点击右侧输出圆点，再点击目标输入圆点可以建立连接。

图片生成 · Codex

使用当前对话的 Codex 图像工具。网页提交任务后显示「等待 Codex 图像工具」；在对话中发送任务编号，Codex 执行后结果会自动回到节点。网页无法自行调用对话工具，也不会显示虚假的生成百分比。

红色密度引导

先连接参考图片，在图片上涂红：越红的区域允许更密的纹样。画笔、橡皮、撤销和清空都在节点内。将此节点连接到「遮罩内纹样排布」的密度输入，整体密度控制全部区域，局部倍率控制红色区域。

模型 UV 与白色遮罩

上传含 UV 的 OBJ 并读取 UV，或直接导入白底黑外的遮罩。纹样节点只在白色范围内排布；本地排布与 Codex 图片生成分别标明。Blender 使用独立管线，不会随图片生成自动运行。

版本与导出

每次生成保存独立版本。用节点中的版本选择或前后箭头回退；单图下载、节点打包与全项目打包均可使用。导出项目 JSON 可保存节点参数和连接。
