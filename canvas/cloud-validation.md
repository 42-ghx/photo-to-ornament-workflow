# 当前运行的验收

此 skill 不携带旧完整包的云端运行记录或旧鼎模型。历史校验结果不能证明当前节点已完成。

四步图片以当前版本的轮廓、透明度、剪影和高度对应关系验收。UV 匹配检查当前目标 OBJ 的已有 UV、方向和裁切；本地铺排检查遮罩外像素与输入保留。

明确要求几何时，先提供当前已确认的同尺寸 PNG 高度图和材料遮罩，填写尺寸，再运行 Blender 节点。每次几何输出产生独立 `scale_checks.json` 和 `fbx_uv_checks.json`，两者均通过才显示完成。未安装可选依赖或 Blender 时，界面将报告缺少条件。

工作台测试命令和依赖说明见 [工作台说明](README.md)。
