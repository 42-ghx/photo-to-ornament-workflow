# 完整节点工作台项目包

下载本目录的 `photo-to-ornament-workflow-full.zip`：登录有权访问此私有仓库的 GitHub 账号，打开该文件，再点击 **Download / Download raw file**。完整 ZIP 使用 Git LFS 保存。

此包包含源码、当前可编辑画板、13 个节点、15 个历史版本、上传的 CylinderPipe.obj、Codex 生成图、UV / 密度资料及 Blender / FBX 结果。解压后阅读 `PACKAGE_START.md`，使用附带的 Windows 或 Linux / macOS 启动脚本。

Python 3.12 和 Blender 安装目录、虚拟环境、Git 历史及账号凭证不在包内。图片生成通过 Codex 对话桥接；独立网页不能自行调用聊天中的图像工具。

完整 ZIP 的 SHA256 位于同名 `.sha256` 文件。解压后 `PACKAGE_MANIFEST.json` 提供逐文件校验值。

如使用 Git 获取本分支，安装 Git LFS 后执行 `git lfs pull` 获取真实文件。本分支用于下载，不修改 main。
