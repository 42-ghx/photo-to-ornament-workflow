# 照片转纹样浮雕

以原照片的可见结构为依据；保留输入和每次确认的版本。生成式展平与高度是艺术重建，不是测量值。照片明暗、锈色与阴影不能直接判作空洞或深度。

## 已确认的工作原则

- 遮罩只表达材料存在：白色材料，黑色外部和指定贯通镂空。刻线、眼眶、凹槽、瞳部下方支撑面仍为白色；它们的深浅由高度图表达。
- 保持完整纹样、主次形体、真实厚度和关键特征可读性。独立浮雕可以按用户要求解释为镂空；不要声称器物照片本身具有这些孔洞。
- **保留已确认的细节。取消将浮雕统一量化为6级平台、整面抹平或额外全局平滑的默认做法。** 该试验被用户否定，已恢复Before细节。
- 区分底厚与浮雕起伏。降低浮雕50%时，只做 `新Z = 底厚 + 0.5 × (旧Z − 底厚)`；保持侧壁、底面和轮廓不动，不能把整个Z轴缩小。
- 只有明确需要修局部问题时，限制区域并保留可比较的副本；不要替用户删细节。建模前已有的照片高度采样处理与建模后新增平滑要分开记录。
- 尺寸、观看距离、纹样区域与背面开闭按当前任务确定。本包案例是宽1 m、观看5 m的独立纹样浮雕；这些参数不是所有新资产的默认真实尺寸。

## 照片与地图

用当前客户端可用的图像编辑工具（本案为内置image_gen），按其要求先查看本地参考。Python仅用于读取、QA和几何采样，不用其代替图像编辑。

1. 透明抠图：移除背景、展台、投影，保留器物视角、真实开口和全部可见结构。
2. 柔和去光照：减弱暖光、强反光与大面积阴影，保留读形所需的局部明暗；不称为测量反照率。
3. 单独输出材料遮罩：展平指定纹样，保留连续连接，分清刻线和空洞，不保留矩形底板。
4. 输出丰富连续的高度：区别主形体、次形体和浅刻线，保存坡度及细节；灰度表达深度，排除光照、AO和锈斑噪声。高度与遮罩共享布局，检查错位及黑凹槽误删问题。

用户要求先确认地图时，在图阶段交付并等待；用户已要求建模或整套执行时继续，不重复请求确认。示例提示词见[照片提示词](references/ding_prompts.json)，仅借鉴约束，按新照片的结构、部件数量和区域改写，不能套用本例“四拱三圆”的形状。

## 高模、循环边与UV

读取[建模说明](references/geometry.md)，优先使用`scripts/build_quad_uv.py`和`scripts/build_scene.py`。实体只生成在遮罩材料区域；刻线以高度表现，不通过删面穿孔。模型保持足够高的采样密度，本流程的密集四边面是高模表面采样，不等于动画低模拓扑。

侧壁按恒定Z高度建立横向轮廓循环边；UV分正面、厚度、底面。厚度按各横向循环边分带，并加必要纵向接缝以打开环带。保留镂空内部侧壁。本例为材料轮廓内封闭底面，不另加矩形背板；新任务明确要求开放背面时，调整建模及边界验收，不能沿用水密判据。

细节确认后调整浮雕强度，使用`scripts/scale_relief.py`，从确认的源版本计算，避免连续减半累积误差。该脚本保留原有XY、底面、侧壁、索引、接缝及UV，仅修改正面Z。不要重新画高度图来完成简单的强度调整。

程序化磨损是可选阶段。读取[磨损说明](references/wear.md)，使用用户的Edge Damage节点组副本，限制局部权重，保护刻线、轮廓、循环边与UV，保留干净版。本包当前认可模型未添加新磨损。

## 验收与交付

检查纹样完整、刻线/镂空语义、细节、侧视底厚和浮雕幅度、循环边、法线、预期边界、UV岛及重导入结果。封闭实体检查水密；开放背面检查边界是否符合预期。

交付真实几何FBX与可编辑.blend，导入Blender供查看；检查重新导入的坐标、面数和UV。未连接Blender MCP时仍可后台生成FBX和.blend，再打开本地工程；不要把“文件生成”说成“已自动导入”。地图及提示词一并保留，尺寸与高度量程写入元数据。

当前认可状态见[鼎案例](references/accepted_case.json)。迁移、新电脑连接及已验证范围见包根目录的`START_HERE.md`和`MIGRATION.md`；不要把本地账号登录等同于文件、软件、技能或MCP凭证迁移。
